# A1. 逆引き

4つの入口から本編へ ／ 順番に読む必要はありません

> 📅 作成: 2026-08-29 / 更新: 2026-08-29

[資料トップへ戻る](../README.md)

## この付録の使い方

- **手が止まったときに引くもの**です。通読は不要です
- 4つの入口があります。**いま分かっていること**に近い入口から入ってください

## 4つの入口

1. [やりたいことから引く](#1-a11-やりたいことから引く)
2. [エラー番号から引く](#2-a12-エラー番号から引く)
3. [他の言語の構文から引く](#3-a13-他の言語の構文から引く)
4. [用語から引く](#4-a14-用語から引く)

## 1. A1.1 やりたいことから引く

### 型を書く

| やりたいこと | 書き方 | 詳しくは |
|---|---|---|
| 取りうる値を限定したい | `type S = "a" \| "b";` | [04.3](04-型の基本.md) |
| `enum` のようなものが欲しい | 文字列リテラルの union | [04.3](04-型の基本.md) |
| プロパティを省略可能にしたい | `age?: number` | [04.2](04-型の基本.md) |
| 書き換えを禁止したい | `readonly` | [04.1](04-型の基本.md) |
| 2つの型を合体したい | `A & B` | [04.4](04-型の基本.md) |
| 値をそのまま型にしたい | `as const` | [04.3](04-型の基本.md) |
| 一部だけ省略可能にしたい | `Partial<T>` | [A4.1](A4-型レベルプログラミング.md) |
| 特定のキーだけ取り出したい | `Pick<T, K>` / `Omit<T, K>` | [A4.1](A4-型レベルプログラミング.md) |
| 同じ形の ID を取り違えたくない | ブランド型 | [05.4](05-構造的型付け.md) |

### 値を扱う

| やりたいこと | 書き方 | 詳しくは |
|---|---|---|
| union のどれか判定したい | `typeof` / `in` / 判別可能ユニオン | [08](08-型の絞り込み.md) |
| 分岐の漏れを検出したい | `never` による網羅性チェック | [08.5](08-型の絞り込み.md) |
| 判定を関数に切り出したい | `v is T` | [08.4](08-型の絞り込み.md) |
| `null` のとき既定値を使いたい | `??`（`\|\|` ではない） | [04.5](04-型の基本.md) |
| 外部から来た JSON を安全に使いたい | `unknown` ＋ 型ガード | [06.2](06-any-unknown-アサーション.md)・[A3.1](A3-実務パターン集.md) |
| 失敗を戻り値で返したい | `Result<T, E>` | [11.4](11-非同期とエラー処理.md)・[A2.1](A2-型レシピ集.md) |

### 環境・設定

| やりたいこと | 方法 | 詳しくは |
|---|---|---|
| `.ts` をすぐ実行したい | `npx tsx file.ts` | [02.3](02-実行環境.md) |
| 型検査だけしたい | `npx tsc --noEmit` | [02.2](02-実行環境.md) |
| 実際に使われる設定を見たい | `npx tsc --showConfig` | [03.4](03-tsconfig.md) |
| Node の型を使いたい | `@types/node` ＋ `"types": ["node"]` | [02.4](02-実行環境.md) |

## 2. A1.2 エラー番号から引く

> [!NOTE]
> **エラーメッセージは既定で英語です。**
> `npx tsc --locale ja` で日本語になります。ただし<strong>検索するときは英語のほうが情報が見つかります。</strong>番号（`TS2322` など）で検索するのが最も確実です。

### 型の不一致

| 番号 | メッセージ（抜粋） | 原因と対処 | 詳しくは |
|---|---|---|---|
| `TS2322` | Type 'X' is not assignable to type 'Y'. | 代入しようとした型が合わない。`strictNullChecks` による `null` の混入が多い | [03.2](03-tsconfig.md) |
| `TS2345` | Argument of type 'X' is not assignable to parameter of type 'Y'. | 引数の型が合わない | [07.1](07-関数の型.md) |
| `TS2353` | Object literal may only specify known properties… | <strong>余剰プロパティチェック。</strong>打ち間違いか、意図的な追加 | [05.2](05-構造的型付け.md) |
| `TS2339` | Property 'x' does not exist on type 'Y'. | union のまま使っている。絞り込みが要る | [08](08-型の絞り込み.md) |

### null・undefined

| 番号 | メッセージ（抜粋） | 原因と対処 | 詳しくは |
|---|---|---|---|
| `TS18048` | 'x' is possibly 'undefined'. | `?.` か `??`、または `if` で確かめる | [04.5](04-型の基本.md) |
| `TS2531` | Object is possibly 'null'. | 同上 | [04.5](04-型の基本.md) |
| `TS18046` | 'e' is of type 'unknown'. | `catch` の変数。`instanceof Error` で確かめる | [11.3](11-非同期とエラー処理.md) |

### any・型の宣言

| 番号 | メッセージ（抜粋） | 原因と対処 | 詳しくは |
|---|---|---|---|
| `TS7006` | Parameter 'x' implicitly has an 'any' type. | 引数に型を書く。**TS7** **7 では `strict` が既定で有効** | [03.2](03-tsconfig.md) |
| `TS2693` | 'X' only refers to a type, but is being used as a value here. | **型を値として使った。**`interface` に `instanceof` は使えない | [01.3](01-背景.md) |
| `TS2591` | Cannot find name 'node:fs'. …install type definitions for node? | **TS7** `@types/node` と `"types": ["node"]` の両方が要る | [02.4](02-実行環境.md) |
| `TS2564` | Property 'x' has no initializer… | クラスのプロパティを初期化する | [03.2](03-tsconfig.md) |

### 設定・モジュール

| 番号 | メッセージ（抜粋） | 原因と対処 | 詳しくは |
|---|---|---|---|
| `TS5112` | tsconfig.json is present but will not be loaded… | **TS7** **コマンドラインにファイル名を書くと設定が無視される** | [02.2](02-実行環境.md) |
| `TS1064` | The return type of an async function must be the global Promise<T> type. | `async` の戻り値を `Promise<T>` にする | [11.1](11-非同期とエラー処理.md) |
| `TS2307` | Cannot find module 'x' or its corresponding type declarations. | 型定義がない。`@types` を探すか自分で書く | [10.4](10-モジュールと宣言ファイル.md) |

### 実行時のエラー（型検査では出ない）

| メッセージ | 原因 | 詳しくは |
|---|---|---|
| `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX` | **Node型ストリップ** `enum` などが使われている | [02.3](02-実行環境.md) |
| `ERR_MODULE_NOT_FOUND` | **ESM** 拡張子を省略した | [10.2](10-モジュールと宣言ファイル.md) |
| `ERR_REQUIRE_ESM` | CJS から ESM を `require` した | [10.2](10-モジュールと宣言ファイル.md) |
| `__dirname is not defined` | **ESM** `import.meta.dirname` を使う | [10.2](10-モジュールと宣言ファイル.md) |
| `x is not a function` | `as` で嘘をついた、または default export の食い違い | [06.3](06-any-unknown-アサーション.md)・[10.2](10-モジュールと宣言ファイル.md) |

## 3. A1.3 他の言語の構文から引く

### JavaScript から

| JavaScript でのやり方 | TypeScript で足すこと | 詳しくは |
|---|---|---|
| `const x = 1;` | そのままでよい（推論される） | [04.1](04-型の基本.md) |
| `function f(a, b) {}` | 引数に型を書く（**strict** では必須） | [07.1](07-関数の型.md) |
| `JSON.parse(s)` | 戻り値は `any`。`unknown` で受けて検証する | [06.2](06-any-unknown-アサーション.md) |
| `arr.filter(x => x)` | 型を絞りたいなら `(x): x is T =>` | [08.4](08-型の絞り込み.md) |
| `catch (e) { e.message }` | `e` は `unknown`。`instanceof Error` で確かめる | [11.3](11-非同期とエラー処理.md) |

### Java から

| Java | TypeScript | 詳しくは |
|---|---|---|
| `enum Status { A, B }` | `type Status = "A" \| "B";` | [04.3](04-型の基本.md) |
| `Optional<T>` | `T \| undefined` と `?.`／`??` | [04.5](04-型の基本.md) |
| `implements` | **不要**（形が合えば互換）。書いてもよい | [05.3](05-構造的型付け.md) |
| `x instanceof MyInterface` | <strong>書けない。</strong>型ガード関数を書く | [08.4](08-型の絞り込み.md) |
| `List<String>` | `string[]` | [04.1](04-型の基本.md) |
| `Map<K,V>` | `Map<K,V>` または `Record<K,V>` | [A4.1](A4-型レベルプログラミング.md) |
| `throws IOException` | **型に現れない。**`Result` を検討する | [11.4](11-非同期とエラー処理.md) |
| `<T extends Comparable>` | `<T extends { ... }>` | [09.2](09-ジェネリクス.md) |

### C# から

| C# | TypeScript | 詳しくは |
|---|---|---|
| `string?`（nullable） | `string \| null` または `string \| undefined` | [04.5](04-型の基本.md) |
| `??` | `??`（同じ） | [04.5](04-型の基本.md) |
| `?.` | `?.`（同じ） | [04.5](04-型の基本.md) |
| `(int)obj`（キャスト） | `as`。**実行時に検査されない** | [06.3](06-any-unknown-アサーション.md) |
| `record` | `type` ＋ `readonly` | [04.2](04-型の基本.md) |
| `switch` の網羅性 | `never` による網羅性チェック | [08.5](08-型の絞り込み.md) |
| `where T : new()` | <strong>書けない。</strong>コンストラクタを引数で渡す | [09.4](09-ジェネリクス.md) |
| `typeof(T)` | <strong>書けない。</strong>型引数は実行時に消える | [09.4](09-ジェネリクス.md) |
| `in` / `out`（変性） | <strong>指定しない。</strong>構造から自動で決まる | [09.4](09-ジェネリクス.md) |

## 4. A1.4 用語から引く

| 用語 | 意味 | 詳しくは |
|---|---|---|
| 型消去 | 型が実行時に残らないこと。TypeScript の型はすべて消える | [01.2](01-背景.md) |
| 構造的型付け | **名前ではなく形**で互換を判定する方式 | [05.1](05-構造的型付け.md) |
| 名前的型付け | 型の名前が一致しないと互換にならない方式（Java・C#） | [05.1](05-構造的型付け.md) |
| 余剰プロパティチェック | オブジェクトリテラルを直接書いたときだけ、余分なプロパティを弾く仕組み | [05.2](05-構造的型付け.md) |
| ブランド型 | 実体のない目印を足して、同じ形の型を区別する手法 | [05.4](05-構造的型付け.md) |
| 型アサーション | `as`。**検査を黙らせるだけ**で、値は変わらない | [06.3](06-any-unknown-アサーション.md) |
| 絞り込み（narrowing） | 条件分岐によって、その位置での型が狭まること | [08.1](08-型の絞り込み.md) |
| 判別可能ユニオン | 共通のキーに別々のリテラル型を持たせた union | [08.3](08-型の絞り込み.md) |
| 型ガード | `v is T` を返す関数。絞り込みを関数に切り出す | [08.4](08-型の絞り込み.md) |
| 網羅性チェック | `never` を使い、分岐の漏れをコンパイル時に検出する手法 | [08.5](08-型の絞り込み.md) |
| 変性（共変・反変） | ある型の代わりに、広い／狭い型を使えるかの規則 | [09.4](09-ジェネリクス.md) |
| ESM / CJS | 2つのモジュール方式。`package.json` の `"type"` が決める | [10.2](10-モジュールと宣言ファイル.md) |
| 宣言ファイル（`.d.ts`） | 型だけを書いたファイル。実装は含まない | [10.3](10-モジュールと宣言ファイル.md) |
| 型ストリップ | 型注釈を取り除くだけで実行する方式。Node が採用 | [02.3](02-実行環境.md) |
| Mapped Types | 既存の型のキーを回して新しい型を作る記法 | [A4.2](A4-型レベルプログラミング.md) |
| Conditional Types | 条件によって結果が変わる型（`T extends U ? X : Y`） | [A4.3](A4-型レベルプログラミング.md) |
