目的と現状

目的

読者が資料のコードを手元に写さずに試せるようにする。コードの横の「実行」ボタンで、その場で出力（console.log）を表示する。TypeScript の資料なので、型エラーもその場で見せる。

現状（2026-10-09 実測）

項目値
資料内のコードブロックtypescript 180 ／ shell 39 ／ json 10
実行用サンプルdocs/samples/ に 13 本（ハンズオン含む）。手元の Node で動かす前提
資料が対象にする版TypeScript 7.0.2 ／ Node v26.10.0
TypeScript 7 の npm パッケージmain が無く bin/tsc だけ（npm view で確認）。ブラウザから呼べる JS の API を持たない
ページの JSdocs/js/highlight.js（色付け）のみ

ブラウザで動く変換器は、資料の TypeScript 7 と別物になる。型エラーの文言・検出の細部が資料の記述と食い違う可能性がある（未確認）。食い違いは「進め方」の手順 5・6 のテストで洗い出す。

決めたこと

参考にした jsprimer の仕組み

部分jsprimerこの資料
対象の指定コードブロックの前に <!-- js-console --> を書いたものだけ同じ考え方（data-run）
実行の場所非表示の iframe ＋ postMessage（codemirror-console）Web Worker
編集CodeMirror 5 で編集して再実行textarea で編集して再実行
変換無し（JavaScript をそのまま実行）TypeScript 5.9.3 で型検査と変換
検証power-doctest。式; // => 値 の注記をビルド時に比較テストへ変換同じ書き方の注記を使う

決定（2026-10-09）

論点決定理由
1. 変換器TypeScript 5.9.3 の lib/typescript.js を docs/js/lib/ に置く型エラーを見せられるのはこれだけ。「実行」を押したときだけ読み込む
2. 実行の場所Web Worker無限ループでもページが固まらず、時間切れで止められる
3. 対象の指定<pre data-run> を付けたものだけ断片・Node 専用の例に動かないボタンを並べない
4. 編集textarea に差し替えて編集・再実行できるライブラリを増やさずに「書き換えて試す」を再現する
5. 検証コードに // => 値 の注記を書き、テストで照合する結果を貼っていないコードも検証でき、読者には行の横に答えが見える

注記は data-run を付けるコードにだけ書く。型エラーは注記ではなく、エラー番号（TS2345 等）で照合する。既存の $ npx tsx の結果ブロックと内容が重なるものは、手順 4 で残すか消すかを決める。

作るもの

置き場中身
docs/js/lib/変換器の本体（1 の結果）と、そのライセンス文。版はファイルの先頭のコメントと docs/ZZ-構成.html に記す
docs/js/runner.jspre[data-run] にボタンと出力欄を足す。押されたら変換器を読み込み、型エラーと出力を表示する
docs/js/runner-worker.jsWorker 側。変換したコードを実行し、出力を親へ返す
docs/css/style.cssボタン・出力欄・型エラーの見た目
docs/*.html対象の pre に data-run を付ける。runner.js を読み込む
tests/資料の data-run コードを取り出し、// => 値 の注記を比較に変えて node:test で実行する。型エラーは番号で照合する
  • ボタンと出力欄は JS が足す。HTML には置かないので、Markdown には出ない（md-skip は要らない）
  • JS が動かないときは今のまま（コードと貼った実行結果が読める）

進め方と完了条件

手順

  1. 1〜5 を決める（済）
  2. 変換器の大きさと読込時間を実測し、ここに書く（済）
  3. runner.js と Worker を作り、1 章分（07 章）で試す
  4. 全資料のコードを調べ、data-run を付けるものを一覧にする。結果ブロックの扱いもここで決める
  5. 付けたものに // => 値 の注記を書き、注記を照合するテストを作る
  6. ブラウザでも同じ注記が満たされるかを PlayWright 共有環境で確かめる

完了条件

  • data-run を付けたすべてのコードで、注記の値と型エラー番号がテストで一致する
  • CDN を参照していない
  • 公開 URL で実行できる
  • check-contrast の指摘が 0 件
